## 购买前还要注意什么？

### 1. 线路适合不等于所有地区都一样

CN2 GIA、联通和移动方向的连接信息可以作为选择参考，但无法替代你自己的测试。北京电信、广东电信、上海联通和不同移动网络的访问结果可能不同。

### 2. 流量是有额度的

40G 方案每月 500GB，80G 方案每月 1TB。对于普通网站通常够用，但图片、视频、文件下载和镜像分发会很快消耗流量。不要只看端口速度，还要估算月度出站流量。

如果你不熟悉 Linux，购买后还需要处理 SSH 密钥、系统更新、防火墙、Web 服务器、数据库和备份。控制面板能降低部分操作难度，但不会替你完成这些工作。

### 4. 不要把香港节点当成备案服务器

香港 VPS 位于中国香港，和中国大陆境内云服务器不是同一类资源。是否需要备案、是否满足业务所在地或监管要求，要根据你的具体业务和当地规则判断。

### 5. 先看库存和最终账单

热门配置可能出现库存变化。官方页面当前显示的价格和购物车金额也可能随时间调整，因此表格适合用来做初步比较，真正下单前应以结账页面为准。
